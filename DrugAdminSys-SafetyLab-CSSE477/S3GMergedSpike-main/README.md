# S3GMergedSpike
## Running Instructions
### Server side (in /server)
1. cd into the server folder. 
2. Type `python main.py` and enter

### Client side (in /client)
1. cd into the client folder
2. Type `python app.py` and enter
3. In the UI, press connect/refresh patient list to connect to the server
4. The client displays the simulated inventory for each training substance in mg.
   The amount refreshes automatically and decreases after each administered
   simulated dose; each substance starts with 1000 mg.
